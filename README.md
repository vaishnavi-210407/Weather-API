# 🌦️ Weather API Application

A simple and responsive Weather Application that fetches weather information using an API and displays dynamic weather data through a user-friendly interface.

## 🚀 Features

- 🌡️ Displays current weather information
- 🌍 Search weather by city name
- ☁️ Shows weather conditions and temperature
- 📱 Responsive user interface
- 🔗 Fetches real-time data using a Weather API
- ⚠️ Handles invalid city names and API errors

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
- Fetch API

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/vaishnavi-210407/Weather-API.git
   ```

2. Open the project folder:

   ```bash
   cd Weather-API
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

4. If the project requires an API key, configure your own key according to the API provider's instructions.
